### Step 1: Install Python Dependencies
Open your terminal or command prompt and install the required libraries (streamlit and pymupdf).
```pip install streamlit pymupdf```

### Step 2: Save the Code
Create a new file on your computer and name it something like app.py.
Paste the provided code into that file and save it.

### Step 3: Run the Streamlit App
Navigate to the folder where you saved app.py using your terminal, then run the following command:
```streamlit run app.py```

### Step 4: Use the Browser
Once executed, Streamlit will automatically launch a local web server and open a new tab in  web browser ```(usually at http://localhost:8501)```
